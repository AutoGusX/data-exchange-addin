### Live fixture (to be created in Revit)

One wall, one floor, one column, one beam and two repeated instances, with a known dimension, a
nonzero translation and rotation, and one property per element. Then revision N+1 with one geometry

ids here once it exists.

## Two-user acceptance script (milestone 4)

1. Machine A: `scripts\package.ps1`; send the zip to user B (no config file, no credentials).
2. Both users install per `docs/install-windows.md` and sign in with their own accounts.
3. Both load the same exchange into their own new design and note the revision in the result message.
4. Both check the known dimension with Inspect > Measure, then save, close and reopen.
5. Publish revision N+1 from Revit.
6. Both choose Refresh Exchange and confirm the new revision and the changed geometry.
7. Each adds a sketch of their own before a refresh and confirms it is untouched after.
8. Collect `%LOCALAPPDATA%\FusionDataExchange\logs` from both machines as evidence.
